# 俳句工房の勉強会

主選者2人、作句2担当、独立した読み手1人が、同じ回で並行して外部の例句・公開添削・選評を読む。標準は**1セット8回、初読・照合・記録は1回15分、各担当で計120分が目安**。回ごとに10〜20分で区切れる。第1〜7回はそれぞれ独立した問いで資料を広く集めて読み、第8回に7回分の学びをまとめる。別のセットでは作者・季題・形式を替えて対象を広げる。

## 各回の問いと教材

進行役と資料調査担当が、各回の開始時に、その回だけで学べる問いと教材を決める。学習ノートに薄い分野や、その場で見つかった原典を手がかりに、取り上げる作者・季題・作品形式・手法を選ぶ。標準計画は回数、時間、受講者の役割、記録の順序を示す。各回の問いはセット内の `<課題ID>-brief.md` に短く残せる。初読前に配る場合は、句の出典や評、期待する解釈を伏せる。

資料調査担当は公開原典を探し、既読状況を確かめ、句面と評を分けて用意する。候補には夏井いつきさん・家藤正人さんの公開添削、古典・近代の句と俳論、現代の句集、俳句ポスト365、お〜いお茶新俳句大賞、プレバトなどがある。独立した読み手には別の選者の資料や作者の自註を用意できる。季節と形式の幅はセットを通じて見る。

各回では、問いに関係する候補を複数の作者・選者・媒体から広く探す。問いを比較しやすい教材をいくつか選び、共通で読む例と、担当ごとに深める例を組み合わせる。同じ手法が違う働きをした例や、別の手法で似た効果が出た例も候補にする。教材の量は問いと読み比べにかかる時間に合わせて、進行役と資料調査担当が決める。

第1〜7回の受講は初読に約3分、原典との照合に約8分、記録に約4分を目安にする。実際に照合した資料では、本文の具体語、出典、読みの違いを短く残す。それぞれの記録を第8回のまとめに使う。読んでみたい候補は出典とともに控える。

## 分担と並行作業

| 学ぶ担当 | 人数 | 同じ回で行うこと |
| --- | ---: | --- |
| 主選者A `selector` | 1 | 類想の重なりや採否の根拠を読み、公開の添削・選評と照合する。メインが担当する。 |
| 主選者B `selector-b` | 1 | 別の読みや、言葉を変えたときの得失を検討し、公開の添削・選評と照合する。 |
| 作句・古典と伝統 `writer` | 1 | 主に古典・近代の句や俳論から、季語、写生、取り合わせ、切れが働く場面を考える。 |
| 作句・現代と多様な形式 `writer-b` | 1 | 主に現代俳人や投稿作品から、口語、比喩、字余り、無季、自由律などの手法を考える。 |
| 独立した読み手 `reader` | 1 | 句面を自由に読み、受け取ったことを保存する。自分の初読を保存してから公開の鑑賞や選評を開く。 |

進行役は資料調査担当と各回の問いを決め、配布と記録の確認を行う。資料調査担当は公開原典を探して台帳に登録する。5人の受講者は実行枠に合わせて同じ回の中で交代する。全員分の照合記録を確認したら、進行役と資料調査担当が次の回を始める。

## 教材の台帳と配布

資料調査担当は、その回に配る教材を一組ごとのJSONにまとめる。各担当の初読票を発行する前に、配る教材を `register-material` でセットの台帳 `materials.json` に登録する。登録時に同じ `studies/` 配下の全セットを照合する。別の媒体に載った句でも、表記幅や空白を揃えて本文が一致すれば登録を止める。同じ組を複数の役割で使うときは、一件に使用先をまとめる。別稿を比べる場合もまとめて登録し、本文を原典の順に書く。

```json
{
  "id": "spring-01",
  "roles": ["selector", "selector-b", "writer", "writer-b", "reader"],
  "source": "作品が載っている公開URLまたは書誌・頁",
  "commentary": "別ページに選評がある場合はそのURLまたは書誌・頁",
  "poems": ["原句の本文", "別稿または比較する句の本文"]
}
```

`commentary` は選評・自解などが別の出典の場合に加える。`reader` は読み手向けの教材を示す。第8回に選んだ教材は `transfer` に登録する。新しく選んだ本文は登録時から重複の照合対象になる。台帳にない旧ノートや表記の異なる別稿も、資料調査担当が未読課題の準備時に照合する。

```sh
python3 scripts/study.py register-material haiku-study-01 round-1 教材.json
python3 scripts/study.py register-material haiku-study-01 transfer 未読用教材.json
python3 scripts/study.py materials haiku-study-01
python3 scripts/study.py handout haiku-study-01 reader round-1
```

`handout` の初読では番号と本文だけが出る。最初に発行した票を保存するので、同じ課題の途中で番号や内容が変わらない。初読を保存してから再び `handout` を実行すると、同じ番号に出典と選評が付く。照合記録は、その担当に照合票を発行してから保存できる。受講者には当該段階の出力を渡す。台帳と票の内部記録は進行役と資料調査担当が扱う。

## 初読と照合を分ける

1. **資料調査担当が公開原典を登録し、進行役が初読の票を配る。** 作者、結果、評、観察メモを伏せた本文を渡す。改稿比較では稿順も伏せる。選評と本文が同じページにある場合は資料調査担当が本文を切り出し、選評のリンクは照合段階に渡す。既読の句は再読の練習に使える。未読例の結果からは外す。
2. **担当が自分の読みを保存する。** まず本文を自由に読み、そのとき受け取ったことを自分の言葉で書く。進行役から期待する解釈や反応を先に示さない。主選者は採否・残す語・別案、作句担当は他の素材に生かせそうな観察を考える。独立した読み手は、初読を「自分の読み」の見出しで自由に記す。
3. **原典と照合する。** 出典名、公開URLまたは手元の版・頁、作者・選者、どの部分を読んだか、既読か今回初めてかを短く残す。選者の公開判断、作者が実際に改めた稿、勉強会の読みを区別する。公開されている選評と解釈が違うときは、本文上どこまで根拠を指せるかを見直す。作品や選評の長い転載は避け、注目した語と要約を記録する。
4. **その回の観察を記録する。** 本文の語、出典、照合で見えたことを各自が短く残す。全員の記録を揃えて回を終える。

## 第8回のまとめ

第1〜7回の記録を持ち寄り、共通して見えたこと、条件によって違ったこと、読みや判断が分かれたことを、具体例と出典を添えて整理する。進行役は、作句・添削でまた使えそうな見方を学習ノートに残す。見方が一つに決まらない場合は、それぞれが働いた条件を書く。まだ調べたい分野は次のセットの候補として控える。

進行役と資料調査担当は、前7回の照合が揃ってから未読の外部句も選ぶ。受講者は句面だけで初読し、その後、公開評と照らす。まとめた見方が別の作者や季題にも当てはまるかを短く確かめる。俳句経験者の実際の反応を得た場合は、出所を添える。

前の記録を開く前に自分で説明し、時間をおいて別の例で再試行する設計には、人を対象とした想起練習・分散練習の研究を参考にした。この工房で確認するのは、引き継いだ資料を使って未読例の読みに根拠を示せるかどうか。 [Karpicke・Roedigerの想起練習研究](https://learninglab.psych.purdue.edu/downloads/2007/2007_Karpicke_Roediger_JML.pdf) · [Karpicke・Bauernschmidtの分散練習研究](https://pubmed.ncbi.nlm.nih.gov/21574747/)

## 読み手が練習すること

読み手は、自分が受け取ったことを、そのまま記録する。すぐに景が浮かぶ、別の読みが浮かぶ、特に印象に残らない、どの反応も記録できる。必要なら初読の後で「どの語からそう読んだか」と尋ねる。別の読みが出たときは、その違いを本文で確かめ、両方の根拠を残す。公開選評に照らしても、自分の読みが変わらなければそのまま書く。

本番の独立選評では、練習に出ていない候補の本文を、作者名・稿番号・観察メモ・過去の評を伏せて2人に別々に渡す。それぞれの自由な読みを受け取ってから、必要な点を聞き足す。

## 保存と再開

進行役が新しい識別名を付け、`studies/<セットのID>/` に計画を保存する。`ready` で担当ごとに着手できる課題を一覧にし、`next --block 課題ID` で特定の課題を確認する。各担当には、自分の課題と段階に合う資料だけを渡す。

```sh
python3 scripts/study.py start haiku-study-01
python3 scripts/study.py status haiku-study-01
python3 scripts/study.py ready haiku-study-01 selector
python3 scripts/study.py next haiku-study-01 selector --block round-1
python3 scripts/study.py next haiku-study-01 selector-b --block round-1
python3 scripts/study.py next haiku-study-01 writer --block round-1
python3 scripts/study.py next haiku-study-01 writer-b --block round-1
python3 scripts/study.py next haiku-study-01 reader --block round-1
```

`next` に出る見出しで記録を作り、課題IDと段階を指定して `record` に渡す。今の標準計画では、記録の前に `handout` で票を発行する。進み具合は担当・課題ごとに保存する。次の回は全員の照合記録が揃うと `ready` に出る。新しい題材で一セット始める場合は、別のセットIDを使う。開始済みのセットを再開するときは、そのセットに保存した計画を参照する。

読み手の課題がない計画で開始済みのセットには、`add-readers <セットのID>` で追加できる。追加する人数はそのセットに保存した計画に従う。旧計画で読み手が2人の場合は、両者の初読が揃ってから、それぞれに照合票を発行する。

```sh
python3 scripts/study.py handout haiku-study-01 selector round-1
python3 scripts/study.py record haiku-study-01 selector round-1 attempt 初読.md
python3 scripts/study.py next haiku-study-01 selector --block round-1
python3 scripts/study.py handout haiku-study-01 selector round-1
python3 scripts/study.py record haiku-study-01 selector round-1 review 照合.md
```

途中で時間が来たら、セットのフォルダに下書きを保存する。別のチャットや別の日には「`haiku-study-01` の勉強会の続きを再開し、保存済み記録から進められる課題を確認してください」と伝える。提出後に気づいたことは照合や次の課題に追記する。別の計画で始める場合は、`study-plan.json` を参考にし、`start --plan 計画.json 新しいセットのID` を使う。

## 参照資料

主選者は公開添削・選評・作者の自解から、採否を支えた言葉と改稿で得たもの・失ったものを確かめる。作句担当は[作句の手引き](01_作句の手引き.md)を出発点に、問いに合う原典を読む。独立した読み手は自分の初読を保存してから公開評を開く。個別に蓄積した学習ノートを使う場合は、手元の保存先を指定する。
